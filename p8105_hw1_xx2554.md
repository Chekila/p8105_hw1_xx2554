## Problem 1

``` r
library(tidyverse)

data("penguins", package = "palmerpenguins")
```

The `penguins` dataset contains information about penguins, including
species, island, bill length, bill depth, flipper length, body mass,
sex, and year. The `species` variable includes Adelie, Chinstrap, and
Gentoo penguins, and the `island` variable includes Biscoe, Dream, and
Torgersen. The dataset contains 344 observations and 8 variables. The
mean flipper length is 200.92 mm.

``` r
ggplot(
  penguins,
  aes(
    x = bill_length_mm,
    y = flipper_length_mm,
    color = species
  )
) +
  geom_point()
```
